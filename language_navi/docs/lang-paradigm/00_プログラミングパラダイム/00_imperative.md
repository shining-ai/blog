# 命令型プログラミング

## 命令型プログラミングとは

> 命令型プログラミングとは、コンピュータに「何をどのように行うか」を順序立てて指示する方式であり、プログラムの状態を変化させる文（ステートメント）の列として処理を記述するパラダイムである。

命令型プログラミングは最も古くから存在するプログラミングパラダイムの一つであり、機械語やアセンブリ言語に直接対応した考え方を持つ。C言語・Pascal・Basicなどが代表例である。プログラムは変数という「状態」を保持し、代入・条件分岐・ループなどの制御構造によってその状態を変化させながら処理を進める。

このパラダイムの核心は「状態」と「制御フロー」にある。変数は特定の値を保持し、代入文によって上書きされる。ループは繰り返しを表現し、if文は条件に応じて実行経路を分岐させる。これらの仕組みにより、CPUの動作と近い形でアルゴリズムを記述できるため、パフォーマンスの最適化がしやすいという利点がある。

一方で、状態が複数の箇所から変更されるとプログラムの挙動を追いにくくなり、バグの温床になりやすい。これが後述する関数型プログラミングや宣言型パラダイムが生まれた背景でもある。現代の多くの言語は命令型の要素を基礎として持ちながら、他のパラダイムも組み合わせるマルチパラダイム設計を採用している。

## 命令型プログラミングの主要概念

| 概念 | 説明 | 例 |
|------|------|----|
| 変数・状態 | 値を格納し、書き換えられる記憶領域 | `x = 10` |
| 代入文 | 変数の値を更新する操作 | `x = x + 1` |
| 順次実行 | 上から下へ順に命令を実行する | 逐次処理 |
| 条件分岐 | 条件に応じて実行経路を変える | `if / else` |
| ループ | 処理を繰り返す | `for / while` |
| サブルーチン | 処理の塊に名前をつけて再利用する | 関数・手続き |

```python
# 命令型プログラミングの例: 1から10の合計を求める
total = 0          # 状態を初期化
i = 1              # カウンタを初期化

while i <= 10:     # ループで状態を変化させる
    total += i     # 代入によって状態を更新
    i += 1

print(total)       # 55
```

```c
// C言語での例
#include <stdio.h>

int main() {
    int total = 0;
    for (int i = 1; i <= 10; i++) {
        total += i;
    }
    printf("%d\n", total); // 55
    return 0;
}
```

## 使用場面

- システムプログラミング（OS・デバイスドライバ）でCPUの動作を直接制御する場合
- パフォーマンスが重要なアルゴリズム実装（ソート・数値計算）
- 既存の手続き型コードベースのメンテナンス
- 学習目的で制御フローやメモリ管理の基礎を理解する場合
