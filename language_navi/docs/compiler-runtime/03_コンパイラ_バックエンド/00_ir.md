# 中間表現（IR）— 三番地コード・SSA 形式

## 中間表現とは

> 中間表現（Intermediate Representation, IR）とは、コンパイラのフロントエンドとバックエンドの間に位置するプログラムの内部表現であり、ソース言語にもターゲットアーキテクチャにも依存しない形で意味を保持することで、最適化の適用と複数ターゲットへの対応を可能にする。

IR を設けることで、フロントエンドの多様な言語と、バックエンドの多様なアーキテクチャを「M × N」問題から「M + N」問題に削減できる。LLVM IR はこの設計の代表例であり、Clang（C/C++）・Rustc・SwiftC など多数のコンパイラが同じ LLVM バックエンドを共有している。

三番地コード（Three-Address Code, TAC）は最も広く使われる IR の形式で、各命令が「最大2つの入力オペランドと1つの出力」を持つ。`t1 = a + b` のような単純な形に分解することで、最適化アルゴリズムを適用しやすくなる。

SSA 形式（Static Single Assignment）は三番地コードを発展させた形式で、各変数への代入がプログラム全体で1回だけになるよう変数名を添字で区別する（`x1`, `x2`, ...）。制御フローの合流点では φ（ファイ）関数が使われ、どのパスから来たかによって値を選択する。SSA 形式はほぼすべての最新コンパイラ（GCC・LLVM・JVM）が採用しており、最適化・データフロー解析を大幅に簡略化する。

## IR の表現形式比較

| 形式 | 特徴 | 使用例 |
|------|------|--------|
| 三番地コード | 各命令が最大2入力・1出力 | 教育用コンパイラ |
| SSA 形式 | 各変数定義が1回、φ 関数で合流 | LLVM IR・GCC GIMPLE |
| ANF (A-Normal Form) | すべての部分式に名前を付ける | ML 系コンパイラ |
| CPS (継続渡しスタイル) | 制御フローを継続として明示 | Scheme・関数型言語コンパイラ |
| スタックベース | スタックマシン命令 | JVM バイトコード・Python バイトコード |

```python
# 三番地コードと SSA 形式の生成

from dataclasses import dataclass, field
from typing import Union

# --- 三番地コード ---
@dataclass
class TACInstr:
    result: str
    op: str
    arg1: str
    arg2: str = ''

    def __str__(self):
        if self.arg2:
            return f"  {self.result} = {self.arg1} {self.op} {self.arg2}"
        elif self.op == 'copy':
            return f"  {self.result} = {self.arg1}"
        else:
            return f"  {self.result} = {self.op} {self.arg1}"


class TACGenerator:
    """AST から三番地コードを生成するジェネレータ"""
    def __init__(self):
        self.instrs: list[TACInstr] = []
        self.temp_count = 0

    def new_temp(self) -> str:
        self.temp_count += 1
        return f"t{self.temp_count}"

    def emit(self, result, op, arg1, arg2='') -> None:
        self.instrs.append(TACInstr(result, op, arg1, arg2))

    def gen_expr(self, node) -> str:
        """式ノードから TAC を生成し、結果を保持する一時変数名を返す"""
        if hasattr(node, 'value'):  # Num
            t = self.new_temp()
            self.emit(t, 'copy', str(node.value))
            return t
        if hasattr(node, 'name'):   # Var
            return node.name
        if hasattr(node, 'op'):     # BinOp
            l = self.gen_expr(node.left)
            r = self.gen_expr(node.right)
            t = self.new_temp()
            self.emit(t, node.op, l, r)
            return t

    def print_tac(self):
        print("=== 三番地コード ===")
        for instr in self.instrs:
            print(instr)


# 例: x = a + b * c
# これを TAC に変換すると:
#   t1 = copy b
#   t2 = copy c
#   t3 = t1 * t2
#   t4 = copy a
#   t5 = t4 + t3
#   x = copy t5

# --- SSA 変換 ---
class SSAConverter:
    """三番地コードを簡易 SSA 形式に変換するデモ"""
    def __init__(self):
        self.var_versions: dict[str, int] = {}
        self.ssa_instrs: list[str] = []

    def new_version(self, var: str) -> str:
        """変数の新しいバージョン（添字付き）を生成"""
        self.var_versions[var] = self.var_versions.get(var, 0) + 1
        return f"{var}_{self.var_versions[var]}"

    def current_version(self, var: str) -> str:
        """変数の現在のバージョンを返す"""
        v = self.var_versions.get(var, 0)
        return f"{var}_{v}" if v > 0 else var

    def convert(self, instrs: list[TACInstr]) -> None:
        """TAC 命令列を SSA 形式に変換してプリント"""
        print("=== SSA 形式 ===")
        for instr in instrs:
            arg1 = self.current_version(instr.arg1) if instr.arg1 else ''
            arg2 = self.current_version(instr.arg2) if instr.arg2 else ''
            result = self.new_version(instr.result)

            if instr.arg2:
                print(f"  {result} = {arg1} {instr.op} {arg2}")
            else:
                print(f"  {result} = {instr.op} {arg1}" if instr.op != 'copy'
                      else f"  {result} = {arg1}")


# 直接 TAC を作成してデモ
gen = TACGenerator()

# ソースコード: a = 1; b = 2; c = a + b; a = c * 3
instrs = [
    TACInstr('a', 'copy', '1'),
    TACInstr('b', 'copy', '2'),
    TACInstr('t1', '+', 'a', 'b'),
    TACInstr('c', 'copy', 't1'),
    TACInstr('t2', '*', 'c', '3'),
    TACInstr('a', 'copy', 't2'),
]

gen.instrs = instrs
gen.print_tac()
print()

ssa = SSAConverter()
ssa.convert(instrs)
# SSA 形式では a への代入が a_1, a_2 と別々に管理される
```

```
LLVM IR の例（C言語の sum 関数をコンパイルした場合）:

define i32 @sum(i32 %a, i32 %b) {
entry:
  %result = add nsw i32 %a, %b
  ret i32 %result
}

SSA 形式の φ 関数の例（if 文の合流点）:

if.true:
  %x_1 = add i32 %a, 1
  br label %merge

if.false:
  %x_2 = sub i32 %a, 1
  br label %merge

merge:
  %x_3 = phi i32 [ %x_1, %if.true ], [ %x_2, %if.false ]
  ; x_3 は if.true から来た場合 x_1、if.false から来た場合 x_2
```

## 使用場面

- LLVM バックエンドを使うコンパイラ（Clang・Rustc・Swift）での最適化パス
- JVM・CLR バイトコードへのコンパイル前段階の最適化
- 静的解析ツールでのデータフロー解析（未初期化変数検出・定数伝播）
- JIT コンパイラでのランタイム最適化（HotSpot JVM・V8 TurboFan）
