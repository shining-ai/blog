# I/O サブシステムとデバイスドライバ (I/O Subsystem & Device Drivers)

## I/O サブシステムとは

OS の I/O サブシステムとは、

> デバイスドライバを通じてハードウェアデバイスへの統一的なアクセスを提供する OS の構成要素

です。
<br/>

アプリケーションはデバイスの種類を意識せず、`open/read/write/close` という共通インタフェースでデバイスを操作できます。
カーネルは I/O 要求をキューイング・スケジューリングし、CPU 効率を最大化します。

## I/O 制御方式の比較

| 方式 | 動作 | CPU 占有 | 適用場面 |
| --- | --- | --- | --- |
| プログラムドI/O（ポーリング） | CPU がステータスレジスタを繰り返し確認 | 高（ビジーウェイト） | 低レイテンシが重要な組み込み |
| 割り込み駆動I/O | デバイス完了時に割り込みで通知 | 低（他処理を実行可能） | 汎用キーボード・シリアル通信 |
| DMA（Direct Memory Access） | DMAコントローラがメモリ転送を担当、CPU不関与 | 最低（完了割り込みのみ） | 大量データ転送（ディスク・NIC） |

## デバイスドライバの階層

```
アプリケーション
      ↓ システムコール（read/write/ioctl）
   VFS（Virtual File System）
      ↓
 キャラクタデバイス / ブロックデバイス / ネットワークデバイス
      ↓
  デバイスドライバ（カーネルモジュール）
      ↓
  ハードウェア（レジスタ・DMA・IRQ）
```

## デバイスの種類

| デバイス種別 | 特徴 | 例 | /dev エントリ |
| --- | --- | --- | --- |
| ブロックデバイス | ランダムアクセス可、ブロック単位転送 | HDD・SSD・NVMe | `/dev/sda`, `/dev/nvme0n1` |
| キャラクタデバイス | シーケンシャルアクセス、バイト単位転送 | キーボード・シリアル・/dev/null | `/dev/tty`, `/dev/input/event0` |
| ネットワークデバイス | パケット単位、ファイルシステムに現れない | NIC・ループバック | `eth0`, `lo`（ifconfig） |

## バッファリングとキャッシュ

| 機構 | 説明 |
| --- | --- |
| ページキャッシュ | カーネルがブロックデバイスの読み書きをメモリにキャッシュ |
| `sync` / `fsync` | キャッシュをディスクへ強制書き出し |
| `fflush` | ユーザ空間の stdio バッファをカーネルへ送出 |
| `O_DIRECT` | ページキャッシュを迂回してデバイスへ直接I/O |
| `O_SYNC` | 書き込みごとにデバイスへの永続化を保証 |

## 実装

```c title="ioctl と O_NONBLOCK / O_DIRECT を使ったI/O（C）"
#include <stdio.h>
#include <stdlib.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <linux/fs.h>
#include <errno.h>
#include <string.h>

/* ブロックデバイスのセクタ数を取得 */
void show_block_device_info(const char *path) {
    int fd = open(path, O_RDONLY);
    if (fd < 0) {
        perror("open");
        return;
    }

    unsigned long long sectors = 0;
    if (ioctl(fd, BLKGETSIZE64, &sectors) == 0) {
        printf("%s のサイズ: %llu バイト (%.1f GiB)\n",
               path, sectors, (double)sectors / (1024.0 * 1024 * 1024));
    } else {
        fprintf(stderr, "ioctl BLKGETSIZE64 失敗: %s\n", strerror(errno));
    }
    close(fd);
}

/* O_NONBLOCK でノンブロッキング読み取り */
void nonblocking_read_example(void) {
    /* /dev/stdin をノンブロッキングで開く */
    int fd = open("/dev/stdin", O_RDONLY | O_NONBLOCK);
    if (fd < 0) { perror("open"); return; }

    char buf[256];
    ssize_t n = read(fd, buf, sizeof(buf) - 1);
    if (n < 0) {
        if (errno == EAGAIN || errno == EWOULDBLOCK) {
            printf("データなし（ノンブロッキング）\n");
        } else {
            perror("read");
        }
    } else {
        buf[n] = '\0';
        printf("読み取り %zd バイト: %s\n", n, buf);
    }
    close(fd);
}

int main(void) {
    /* ブロックデバイス情報（root権限が必要な場合あり） */
    show_block_device_info("/dev/sda");

    /* ノンブロッキングI/O */
    nonblocking_read_example();

    /* O_DIRECT: 512バイトアラインのバッファが必要 */
    /* 実際の使用例: Database の Direct I/O */
    int fd = open("/tmp/test_direct.bin", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd >= 0) {
        /* ページキャッシュ経由の通常書き込み */
        const char *msg = "hello direct io\n";
        write(fd, msg, strlen(msg));
        fsync(fd);  /* 明示的にディスクへ書き出し */
        close(fd);
        printf("fsync 完了\n");
        unlink("/tmp/test_direct.bin");
    }
    return 0;
}
```

import selectors
import sys
import os
import struct
import asyncio

# --- selectors を使ったマルチプレクサI/O ---
def selectors_example():
    sel = selectors.DefaultSelector()

    # 標準入力を登録（読み取り可能になったら通知）
    sel.register(sys.stdin, selectors.EVENT_READ, data="stdin")

    print("入力待ち（3秒でタイムアウト）...")
    events = sel.select(timeout=3.0)
    if events:
        for key, mask in events:
            if key.data == "stdin":
                line = key.fileobj.readline()
                print(f"受信: {line.strip()}")
    else:
        print("タイムアウト: 入力なし")

    sel.close()

# --- /dev/input イベント読み取り（Linux キーボード/マウス）---
def read_input_event(device_path: str, max_events: int = 5):
    """
    /dev/input/eventX からキーボード・マウスイベントを読み取る。
    input_event 構造体: timeval(16B) + type(2B) + code(2B) + value(4B) = 24B
    """
    EVENT_SIZE = 24
    FORMAT = 'llHHI'  # long, long, unsigned short x2, unsigned int

    if not os.path.exists(device_path):
        print(f"{device_path} が存在しません（root権限または仮想環境が必要）")
        return

    try:
        with open(device_path, 'rb') as f:
            for _ in range(max_events):
                data = f.read(EVENT_SIZE)
                if len(data) < EVENT_SIZE:
                    break
                tv_sec, tv_usec, ev_type, code, value = struct.unpack(FORMAT, data)
                print(f"type={ev_type:#04x} code={code:#04x} value={value}")
    except PermissionError:
        print(f"{device_path} の読み取りにはroot権限が必要です")

if __name__ == '__main__':
    selectors_example()
    asyncio.run(async_io_example())

## 使用場面

- **カーネルモジュール開発**: `module_init` / `module_exit` でドライバを実装し、`/dev` エントリを作成
- **組み込みドライバ**: GPIO・SPI・I2C を ioctl で制御（Raspberry Pi など）
- **高速ストレージ (NVMe)**: `O_DIRECT` + libaio / io_uring でカーネルキャッシュを迂回した低レイテンシI/O
- **イベント監視**: `inotify` で `/dev/input` やファイルシステムの変更を監視
- **データベース**: PostgreSQL・MySQL は `O_DIRECT` / `O_DSYNC` でバッファ管理を自前で実装
