# 設計原則・デザインパターン

SOLID・DRY・GoFの23パターンまで、ソフトウェア設計の原則とデザインパターンを体系的に解説します。

## カテゴリ一覧

- **SOLID原則** — 単一責任・開放閉鎖・リスコフ置換・インターフェース分離・依存性逆転
- **GoF生成パターン** — Singleton・Factory・Abstract Factory・Builder・Prototype
- **GoF構造パターン** — Adapter・Bridge・Composite・Decorator・Facade・Flyweight・Proxy
- **GoF振る舞いパターン** — Strategy・Observer・Command・Iterator・Template Method他
