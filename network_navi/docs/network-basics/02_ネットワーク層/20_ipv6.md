# IPv6 の概要と移行

## IPv6 とは

> IPv4 の 32 ビットアドレス枯渇問題を解決するために設計された 128 ビットの次世代 IP プロトコル

IPv6（Internet Protocol version 6）は RFC 8200 で定義されており、IPv4 の約 43 億アドレスに対して 約 3.4 × 10^38 個という事実上無限のアドレス空間を持ちます。アドレス表記はコロン区切りの 16 進数 8 グループ（例: 2001:0db8:85a3::8a2e:0370:7334）で、連続するゼロは `::` で省略できます。

IPv6 では NAT が不要になり、IPsec が標準サポートされ、ヘッダが単純化されてルータの処理効率が向上しています。

## IPv4 vs IPv6 の比較

| 項目 | IPv4 | IPv6 |
|------|------|------|
| アドレス長 | 32 ビット | 128 ビット |
| アドレス数 | 約 43 億 | 約 3.4 × 10^38 |
| 表記 | 10 進ドット区切り | 16 進コロン区切り |
| ヘッダサイズ | 20〜60 bytes（可変） | 40 bytes（固定） |
| チェックサム | ヘッダにあり | なし（上位層に委任） |
| フラグメント | ルータで可能 | 送信元のみ |
| ブロードキャスト | あり | なし（マルチキャストに統合） |
| NAT | 広く使用 | 原則不要 |
| 自動設定 | DHCP | SLAAC・DHCPv6 |

## IPv6 アドレスの種類

| 種類 | プレフィックス | 説明 |
|------|--------------|------|
| グローバルユニキャスト | 2000::/3 | インターネット上でルーティング可能 |
| リンクローカル | fe80::/10 | 同一リンク内のみ有効 |
| ユニークローカル | fc00::/7 | プライベートアドレス相当 |
| マルチキャスト | ff00::/8 | 複数受信者への同時送信 |
| ループバック | ::1/128 | 自分自身（127.0.0.1 相当） |

## IPv4/IPv6 移行技術

```
デュアルスタック: 1 台のホストが IPv4 と IPv6 両方を使用
トンネリング (6in4): IPv6 パケットを IPv4 でカプセル化
NAT64: IPv6 ホストが IPv4 ホストと通信するための変換
DS-Lite: IPv6 網上で IPv4 接続を提供
```

```python
import socket
import ipaddress

def analyze_ipv6(addr_str: str) -> dict:
    """IPv6 アドレスを解析する"""
    try:
        addr = ipaddress.IPv6Address(addr_str)
        return {
            "compressed":    str(addr.compressed),
            "expanded":      str(addr.exploded),
            "is_global":     addr.is_global,
            "is_private":    addr.is_private,
            "is_link_local": addr.is_link_local,
            "is_loopback":   addr.is_loopback,
            "is_multicast":  addr.is_multicast,
            "packed_hex":    addr.packed.hex(),
        }
    except ValueError as e:
        return {"error": str(e)}

def get_ipv6_addresses() -> list[dict]:
    """現在のホストの IPv6 アドレスを取得する"""
    addresses = []
    try:
        # getaddrinfo でホスト名から IPv6 アドレスを取得
        results = socket.getaddrinfo(
            socket.gethostname(), None, socket.AF_INET6
        )
        for r in results:
            ip = r[4][0]
            if ip not in [a["address"] for a in addresses]:
                addresses.append({"address": ip, "scope": r[4][3]})
    except socket.gaierror:
        pass
    return addresses

def check_ipv6_connectivity(host: str = "ipv6.google.com") -> bool:
    """IPv6 接続確認"""
    try:
        socket.getaddrinfo(host, 80, socket.AF_INET6)
        with socket.socket(socket.AF_INET6, socket.SOCK_STREAM) as s:
            s.settimeout(3)
            s.connect((host, 80))
            print(f"IPv6 接続成功: {host}")
            return True
    except (socket.gaierror, OSError) as e:
        print(f"IPv6 接続失敗: {e}")
        return False

# デモ
test_addrs = [
    "2001:0db8:85a3:0000:0000:8a2e:0370:7334",  # グローバル（ドキュメント用）
    "fe80::1",                                   # リンクローカル
    "::1",                                       # ループバック
    "ff02::1",                                   # マルチキャスト
]

print("=== IPv6 アドレス解析 ===")
for addr in test_addrs:
    info = analyze_ipv6(addr)
    print(f"\n{addr}")
    for k, v in info.items():
        print(f"  {k:<16}: {v}")

print("\n=== IPv6 接続確認 ===")
check_ipv6_connectivity()
```
