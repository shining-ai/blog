# HTTP/1.1 の構造（リクエスト・レスポンス）

## HTTP/1.1 とは

> HyperText Transfer Protocol バージョン 1.1（RFC 7230〜7235）：Web ブラウザとサーバ間でリソースを交換するための、テキストベースのリクエスト・レスポンス型プロトコル

HTTP/1.1 は 1997 年に RFC 2068 として標準化され（後に RFC 7230 系に改訂）、今日も広く使われている Web の基礎プロトコルです。TCP 上で動作し、クライアントがリクエストを送信し、サーバがレスポンスを返すシンプルな仕組みです。

HTTP/1.0 からの主な改善点は「持続的接続（Keep-Alive）」の標準化です。HTTP/1.0 では 1 リクエストごとに TCP コネクションを確立・切断していましたが、1.1 では `Connection: keep-alive` が既定となり、同一 TCP コネクションで複数のリクエストを連続して送れるようになりました。

ただし HTTP/1.1 には「HOL ブロッキング」の問題があります。パイプライニング（複数リクエストを続けて送る機能）があるものの、レスポンスはリクエスト順に返す必要があるため、最初のレスポンスが遅れると後続も待たされます。これを解決したのが HTTP/2 の多重化です。

## HTTP/1.1 リクエスト構造

| 部位 | 例 | 説明 |
|------|-----|------|
| リクエスト行 | `GET /index.html HTTP/1.1` | メソッド・パス・バージョン |
| Host ヘッダ | `Host: example.com` | 必須ヘッダ（バーチャルホスト） |
| その他ヘッダ | `Accept: text/html` | 任意の追加情報 |
| 空行 | `\r\n` | ヘッダとボディの区切り |
| ボディ | `{"key":"value"}` | POST/PUT 等で使用 |

## HTTP メソッド

| メソッド | 用途 | 冪等性 | ボディ |
|---------|------|--------|--------|
| GET | リソース取得 | あり | なし |
| POST | リソース作成・処理 | なし | あり |
| PUT | リソース置換 | あり | あり |
| PATCH | リソース部分更新 | なし | あり |
| DELETE | リソース削除 | あり | なし |
| HEAD | レスポンスヘッダのみ取得 | あり | なし |
| OPTIONS | 利用可能メソッドの確認 | あり | なし |

## 主な HTTP ステータスコード

| コード | 分類 | 代表例 |
|--------|------|--------|
| 1xx | 情報 | 100 Continue |
| 2xx | 成功 | 200 OK, 201 Created, 204 No Content |
| 3xx | リダイレクト | 301 Moved Permanently, 304 Not Modified |
| 4xx | クライアントエラー | 400 Bad Request, 401, 403, 404, 422, 429 |
| 5xx | サーバエラー | 500 Internal Server Error, 502, 503 |

```python
from dataclasses import dataclass, field
from typing import Optional
import json

@dataclass
class HTTPRequest:
    method: str
    path: str
    headers: dict = field(default_factory=dict)
    body: bytes = b''
    version: str = "HTTP/1.1"

    def to_bytes(self) -> bytes:
        lines = [f"{self.method} {self.path} {self.version}"]
        if self.body:
            self.headers.setdefault("Content-Length", str(len(self.body)))
        for k, v in self.headers.items():
            lines.append(f"{k}: {v}")
        request_str = "\r\n".join(lines) + "\r\n\r\n"
        return request_str.encode() + self.body

    def __str__(self):
        return self.to_bytes().decode(errors="replace")

@dataclass
class HTTPResponse:
    status_code: int
    reason: str
    headers: dict = field(default_factory=dict)
    body: bytes = b''
    version: str = "HTTP/1.1"

    STATUS_MAP = {
        200: "OK", 201: "Created", 204: "No Content",
        301: "Moved Permanently", 304: "Not Modified",
        400: "Bad Request", 401: "Unauthorized",
        403: "Forbidden", 404: "Not Found",
        500: "Internal Server Error",
    }

    def to_bytes(self) -> bytes:
        reason = self.reason or self.STATUS_MAP.get(self.status_code, "Unknown")
        lines = [f"{self.version} {self.status_code} {reason}"]
        if self.body:
            self.headers.setdefault("Content-Length", str(len(self.body)))
        for k, v in self.headers.items():
            lines.append(f"{k}: {v}")
        response_str = "\r\n".join(lines) + "\r\n\r\n"
        return response_str.encode() + self.body

    def __str__(self):
        return self.to_bytes().decode(errors="replace")

def simulate_http_exchange():
    """HTTP/1.1 のリクエスト・レスポンス交換シミュレーション"""

    # GET リクエスト
    req_get = HTTPRequest(
        method="GET",
        path="/api/users/1",
        headers={"Host": "api.example.com", "Accept": "application/json",
                 "Connection": "keep-alive"},
    )
    print("=== GET リクエスト ===")
    print(req_get)

    # 200 OK レスポンス
    body = json.dumps({"id": 1, "name": "Alice", "email": "alice@example.com"}).encode()
    res_ok = HTTPResponse(
        status_code=200, reason="OK",
        headers={"Content-Type": "application/json", "Connection": "keep-alive"},
        body=body,
    )
    print("=== 200 OK レスポンス ===")
    print(res_ok)

    # POST リクエスト
    post_body = json.dumps({"name": "Bob", "email": "bob@example.com"}).encode()
    req_post = HTTPRequest(
        method="POST",
        path="/api/users",
        headers={"Host": "api.example.com", "Content-Type": "application/json"},
        body=post_body,
    )
    print("=== POST リクエスト ===")
    print(req_post)

    # 404 レスポンス
    res_404 = HTTPResponse(
        status_code=404, reason="Not Found",
        headers={"Content-Type": "application/json"},
        body=b'{"error":"user not found"}',
    )
    print("=== 404 Not Found レスポンス ===")
    print(res_404)

simulate_http_exchange()
```
