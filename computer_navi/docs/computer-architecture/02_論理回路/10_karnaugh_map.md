# カルノー図と論理式の簡略化

## 概要

カルノー図（Karnaugh Map）とは、

> 真理値表を2次元のグリッドに配置し、隣接するセルをグループ化することで論理式を視覚的に最小化する手法

です。

代数的な操作を行わず、目視でグループを探せるため、4〜5変数程度までの論理回路設計に広く利用されます。

## カルノー図の構成

### 2変数の例

```
      B=0  B=1
A=0 |  0  |  1  |
A=1 |  1  |  1  |
```

グレイコード順（00, 01, 11, 10）で配置するため、隣接するセルは1ビットだけ異なります。

### グループ化のルール

1. **サイズ**: グループは 1, 2, 4, 8, ... 個（2のべき乗）のセルで構成
2. **形状**: 長方形のみ（L字形は不可）
3. **端の折り返し**: 図の上下・左右は繋がっているとみなす
4. **最大化**: できるだけ大きいグループを優先

## 簡略化の例（4変数）

関数 F(A,B,C,D) の真理値表から：

```
CD\AB  00  01  11  10
 00  |  1 |  1 |  1 |  0  |
 01  |  1 |  0 |  0 |  0  |
 11  |  1 |  0 |  0 |  1  |
 10  |  1 |  1 |  1 |  1  |

グループ1（左列 8セル）: A'B'C' → 削除不能

最小化後: F = A'B' + A'C' + ...
```

## 計算量

| 変数数 | カルノー図サイズ | 最大グループ数 |
|---|---|---|
| 2 | 2×2 | 4 |
| 3 | 2×4 | 8 |
| 4 | 4×4 | 16 |
| 5〜 | 3D以上 → Quine-McCluskey 法へ | — |

## 実装（クワイン・マクラスキー法）

```python title="最小化アルゴリズムの基礎"
def count_ones(n: int) -> int:
    return bin(n).count('1')

def combine(a: int, b: int, bits: int) -> int | None:
    """1ビットだけ異なる2つの積項を結合。異なるなら None"""
    diff = a ^ b
    if diff and (diff & (diff - 1)) == 0:  # 1ビットのみ異なる
        return a & b  # 異なるビットをドントケアに
    return None

# 例: ミンタームリスト [0, 1, 3, 5, 7]
minterms = [0, 1, 3, 5, 7]
grouped = {}
for m in minterms:
    grouped.setdefault(count_ones(m), []).append(m)
print(grouped)  # {0: [0], 1: [1, 5], 2: [3, 7], 3: [7]}
```

## 使用場面

- **論理回路設計**: 最小ゲート数の回路を導出
- **PLDプログラミング**: PLA・PAL への論理式入力
- **ハザード除去**: 不要な状態遷移を最小化
