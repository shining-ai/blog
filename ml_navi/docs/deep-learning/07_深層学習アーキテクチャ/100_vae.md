# VAE（変分オートエンコーダ）

## VAE とは

> VAE（Variational Autoencoder：変分オートエンコーダ）とは、潜在空間を**確率分布（通常は正規分布）としてモデル化する**生成モデルである。通常のオートエンコーダが潜在表現を1つの点にマッピングするのに対し、VAE は平均と分散をパラメータとする分布にマッピングし、そこからサンプリングすることで新しいデータを生成できる。

---

## 通常の AE と VAE の違い

```
通常の AE:
  x → [Encoder] → z（点） → [Decoder] → x̂
  問題: 潜在空間に構造がなく、補間や生成が困難

VAE:
  x → [Encoder] → μ, σ^2（正規分布のパラメータ）
                     ↓
             z ~ N(μ, σ^2)（サンプリング）
                     ↓
             [Decoder] → x̂
  利点: 潜在空間が滑らかで、新しいデータを生成可能
```

---

## VAE の数学的背景

### ELBO（Evidence Lower BOund）

VAE の学習目標は対数尤度 log p(x) の最大化だが、直接計算は困難なため、ELBO を最大化する。

```
log p(x) ≥ ELBO

ELBO = E_{q(z|x)}[log p(x|z)] - KL(q(z|x) || p(z))
     = 再構成誤差（最大化）  - KL divergence（最小化）

各項の意味:
  E_{q(z|x)}[log p(x|z)]: 再構成の良さ（高いほど良い）
  KL(q(z|x) || p(z)):     潜在分布の正則化（低いほど良い）
    q(z|x) = N(μ, σ^2): エンコーダが予測する分布
    p(z)   = N(0, I):   事前分布（標準正規分布）
```

### KL Divergence の解析的計算

q(z|x) = N(μ, σ^2) と p(z) = N(0, I) の KL divergence は解析的に計算できる。

```
KL(N(μ, σ^2) || N(0, I)) = -½ Σ_j (1 + log σ_j^2 - μ_j^2 - σ_j^2)

j はそれぞれの潜在次元
```

---

## 再パラメータ化トリック（Reparameterization Trick）

サンプリング操作は微分不可能であるため、勾配を流すために再パラメータ化を行う。

```
問題:
  z ~ N(μ, σ^2) からのサンプリングは微分不可能

解決策（再パラメータ化）:
  ε ~ N(0, I)（固定した確率変数）
  z = μ + σ × ε

この変換により:
  ∂z/∂μ = 1（微分可能）
  ∂z/∂σ = ε（微分可能）
  確率的な操作は ε のサンプリングに分離される
```

---

## 潜在空間の性質

VAE の潜在空間は以下の良い性質を持つ。

| 性質 | 説明 |
|---|---|
| 連続性 | 近い潜在点は近い出力になる |
| 完全性 | 潜在空間のあらゆる点からデータを生成できる |
| 意味的構造 | 潜在次元が意味のある属性に対応することがある |
| 補間 | 2点の補間経路が自然なデータを生成 |

## PyTorch による実装

### VAE の完全実装

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms


class VAE(nn.Module):
    """変分オートエンコーダ（全結合層版）"""
    def __init__(self, input_dim: int = 784, hidden_dim: int = 512,
                 latent_dim: int = 20):
        super().__init__()
        self.latent_dim = latent_dim

        # エンコーダ
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
        )
        # 平均と対数分散を別々に予測
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)

        # デコーダ
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid(),
        )

    def encode(self, x: torch.Tensor):
        """
        Returns:
            mu: [batch, latent_dim]
            logvar: [batch, latent_dim]（分散の対数）
        """
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar

    def reparameterize(self, mu: torch.Tensor, logvar: torch.Tensor) -> torch.Tensor:
        """再パラメータ化トリック"""
        if self.training:
            std = torch.exp(0.5 * logvar)  # σ = exp(log σ^2 / 2)
            eps = torch.randn_like(std)     # ε ~ N(0, I)
            return mu + eps * std           # z = μ + ε × σ
        else:
            return mu  # 推論時は平均を使用

    def decode(self, z: torch.Tensor) -> torch.Tensor:
        return self.decoder(z)

    def forward(self, x: torch.Tensor):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        x_recon = self.decode(z)
        return x_recon, mu, logvar

    def generate(self, num_samples: int, device: str = "cpu") -> torch.Tensor:
        """潜在空間からランダムにサンプリングして生成"""
        self.eval()
        with torch.no_grad():
            z = torch.randn(num_samples, self.latent_dim).to(device)
            return self.decode(z)

    def reconstruct(self, x: torch.Tensor) -> torch.Tensor:
        """入力データの再構成"""
        self.eval()
        with torch.no_grad():
            mu, logvar = self.encode(x)
            z = self.reparameterize(mu, logvar)
            return self.decode(z)
```

### VAE の損失関数

```python
def vae_loss(x_recon: torch.Tensor, x: torch.Tensor,
             mu: torch.Tensor, logvar: torch.Tensor,
             beta: float = 1.0) -> dict:
    """
    VAE の損失関数: Reconstruction Loss + β × KL Divergence
    β > 1 の場合は β-VAE（潜在空間のもつれ解消に有効）

    Args:
        x_recon: 再構成された入力 [batch, input_dim]
        x:       元の入力 [batch, input_dim]
        mu:      潜在空間の平均 [batch, latent_dim]
        logvar:  潜在空間の対数分散 [batch, latent_dim]
        beta:    KL 項の重み
    Returns:
        損失の辞書
    """
    batch_size = x.size(0)

    # 再構成誤差（バイナリクロスエントロピー）
    recon_loss = F.binary_cross_entropy(x_recon, x, reduction='sum') / batch_size

    # KL Divergence: -½ Σ(1 + log σ^2 - μ^2 - σ^2)
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp()) / batch_size

    total_loss = recon_loss + beta * kl_loss

    return {
        "loss": total_loss,
        "recon_loss": recon_loss,
        "kl_loss": kl_loss,
    }
```

### 学習ループ

```python
def train_vae(model, train_loader, num_epochs=100, beta=1.0):
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = model.to(device)
    optimizer = optim.Adam(model.parameters(), lr=1e-3)

    for epoch in range(num_epochs):
        model.train()
        total_loss = 0.0
        total_recon = 0.0
        total_kl = 0.0

        for images, _ in train_loader:
            images = images.view(images.size(0), -1).to(device)
            optimizer.zero_grad()

            x_recon, mu, logvar = model(images)
            losses = vae_loss(x_recon, images, mu, logvar, beta=beta)

            losses["loss"].backward()
            optimizer.step()

            total_loss += losses["loss"].item()
            total_recon += losses["recon_loss"].item()
            total_kl += losses["kl_loss"].item()

        n = len(train_loader)
        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch+1:3d}: "
                  f"Total={total_loss/n:.2f}, "
                  f"Recon={total_recon/n:.2f}, "
                  f"KL={total_kl/n:.2f}")

    return model
```

### 潜在空間の可視化

```python
import matplotlib.pyplot as plt
import numpy as np


def visualize_latent_space(model, data_loader, device, num_classes=10):
    """2次元潜在空間のクラス分布を可視化（latent_dim=2 の場合）"""
    model.eval()
    all_mu = []
    all_labels = []

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.view(images.size(0), -1).to(device)
            mu, _ = model.encode(images)
            all_mu.append(mu.cpu().numpy())
            all_labels.append(labels.numpy())

    all_mu = np.concatenate(all_mu)
    all_labels = np.concatenate(all_labels)

    plt.figure(figsize=(10, 8))
    scatter = plt.scatter(all_mu[:, 0], all_mu[:, 1],
                         c=all_labels, cmap='tab10', alpha=0.5, s=1)
    plt.colorbar(scatter, label="Class")
    plt.xlabel("z[0]")
    plt.ylabel("z[1]")
    plt.title("VAE Latent Space")
    plt.savefig("vae_latent_space.png", dpi=150, bbox_inches='tight')
    plt.close()


def interpolate_latent(model, x1, x2, steps=10):
    """2つのデータ点の潜在空間上の補間"""
    model.eval()
    with torch.no_grad():
        mu1, _ = model.encode(x1)
        mu2, _ = model.encode(x2)

        alphas = torch.linspace(0, 1, steps)
        interpolated = []
        for alpha in alphas:
            z = (1 - alpha) * mu1 + alpha * mu2
            x_gen = model.decode(z)
            interpolated.append(x_gen)

    return torch.stack(interpolated)
```

## β-VAE（解きほぐされた表現）

β > 1 の VAE（β-VAE）は KL 項を強く正則化することで、潜在次元が意味のある属性に対応した**解きほぐされた表現（disentangled representation）** を学習しやすくなる。

```
例: 顔画像の β-VAE
  z_0 → 笑顔の程度
  z_1 → 髪の色
  z_2 → 眼鏡の有無
  z_3 → 顔の向き
  ...

1つの潜在次元を変化させると、1つの属性だけが変化する
```

## 使用場面

- **画像生成**: 手書き文字、顔画像の生成
- **データ拡張**: 少ないデータから新しいサンプルを生成
- **異常検知**: 正常データの分布を学習し、外れ値を検出
- **薬剤分子設計**: 分子構造の潜在空間で新薬候補を探索
- **半教師あり学習**: 潜在表現を下流タスクの特徴量に利用
