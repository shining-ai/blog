# GAN（敵対的生成ネットワーク）

## GAN とは

> GAN（Generative Adversarial Network：敵対的生成ネットワーク）とは、**Generator（生成器）と Discriminator（識別器）の 2 つのネットワークを競わせること**で、リアルなデータを生成できるモデルを学習するフレームワークである。生成器は本物に見せかけた偽データを生成し、識別器は本物と偽物を見分けようとする。この競争によって双方が強化される。

---

## Generator と Discriminator の役割

```
Generator（G）:
  入力: ランダムノイズ z ~ N(0, I)（潜在ベクトル）
  出力: 偽の画像 G(z)
  目的: Discriminator を騙せる「本物らしい」データを生成する

Discriminator（D）:
  入力: 本物の画像 x または 偽の画像 G(z)
  出力: 本物の確率 D(x) ∈ [0, 1]
  目的: 本物（D=1）と偽物（D=0）を正確に識別する

均衡状態（Nash Equilibrium）:
  G が完璧になると D(G(z)) = 0.5（識別できない）
```

---

## Minimax 損失関数

```
min_G max_D V(D, G)
= E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]

Discriminator の学習（D を最大化）:
  - 本物 x に対して D(x) → 1（log D(x) を大きく）
  - 偽物 G(z) に対して D(G(z)) → 0（log(1-D(G(z))) を大きく）

Generator の学習（G を最小化）:
  - D(G(z)) → 1 となるように G を更新
  - 実装では log(1-D(G(z))) の最小化ではなく
    -log(D(G(z))) の最小化を使う（Non-saturating loss）
    理由: 学習初期に勾配が消失しやすいため
```

---

## 学習の不安定性と課題

| 問題 | 説明 | 対策 |
|---|---|---|
| Mode Collapse | G が一部のパターンのみ生成 | Wasserstein GAN、Mini-batch 識別 |
| 訓練の不均衡 | D が G より強くなりすぎる | 学習率の調整、Label Smoothing |
| 勾配消失 | D が完璧になると G への勾配がゼロ | Wasserstein 距離、Spectral Norm |
| チェッカーボード | 転置畳み込みによるアーティファクト | PixelShuffle、Upsampling + Conv |

### Mode Collapse のイメージ

```
データの真の分布: 多様なモード（クラス）が存在
  ○○○  ●●●  △△△  ■■■

Mode Collapse が起きた場合:
  ○○○  ○○○  ○○○  ○○○  ← 1種類しか生成しない
```

## DCGAN（Deep Convolutional GAN）

DCGAN は畳み込みを活用した GAN で、安定した学習のためのアーキテクチャガイドラインを提案した。

| ガイドライン |
|---|
| プーリング層の代わりに Strided Conv（D）/ Fractional-Strided Conv（G）を使用 |
| G と D の両方に BatchNorm を適用（G の出力層と D の入力層を除く） |
| 全結合層を使わず完全畳み込み構造にする |
| G の活性化関数: ReLU（出力層のみ tanh） |
| D の活性化関数: LeakyReLU |

---

## Wasserstein GAN（WGAN）

通常の GAN の損失は JS 乖離度だが、分布が重ならない場合に勾配が消失する。WGAN は Wasserstein 距離を使い、より安定した学習を実現する。

```
WGAN の目標関数:
  min_G max_{D: 1-Lip} E_{x~p_data}[D(x)] - E_{z}[D(G(z))]

D が 1-Lipschitz 連続の制約を満たす条件:
  - 重みクリッピング（WGAN） ← 単純だが性能が劣る場合も
  - Gradient Penalty（WGAN-GP） ← より安定

特徴:
  - 学習が安定し Mode Collapse が起きにくい
  - Wasserstein 距離は学習の進捗を示す良い指標になる
```

## PyTorch による実装

### DCGAN の Generator

```python
import torch
import torch.nn as nn


def weights_init(m):
    """DCGAN の推奨初期化"""
    classname = m.__class__.__name__
    if classname.find('Conv') != -1:
        nn.init.normal_(m.weight.data, 0.0, 0.02)
    elif classname.find('BatchNorm') != -1:
        nn.init.normal_(m.weight.data, 1.0, 0.02)
        nn.init.constant_(m.bias.data, 0)


class DCGANGenerator(nn.Module):
    """DCGAN の Generator（64×64 画像生成）"""
    def __init__(self, nz: int = 100, ngf: int = 64, nc: int = 3):
        """
        Args:
            nz:  潜在ベクトルの次元数
            ngf: Generator のフィルタ基本数
            nc:  出力チャンネル数（RGB=3）
        """
        super().__init__()
        self.main = nn.Sequential(
            # 入力: z ∈ R^nz → [B, nz, 1, 1]
            nn.ConvTranspose2d(nz, ngf * 8, 4, 1, 0, bias=False),
            nn.BatchNorm2d(ngf * 8),
            nn.ReLU(True),
            # → [B, ngf*8, 4, 4]
            nn.ConvTranspose2d(ngf * 8, ngf * 4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ngf * 4),
            nn.ReLU(True),
            # → [B, ngf*4, 8, 8]
            nn.ConvTranspose2d(ngf * 4, ngf * 2, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ngf * 2),
            nn.ReLU(True),
            # → [B, ngf*2, 16, 16]
            nn.ConvTranspose2d(ngf * 2, ngf, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ngf),
            nn.ReLU(True),
            # → [B, ngf, 32, 32]
            nn.ConvTranspose2d(ngf, nc, 4, 2, 1, bias=False),
            nn.Tanh(),
            # → [B, nc, 64, 64]
        )
        self.apply(weights_init)

    def forward(self, z: torch.Tensor) -> torch.Tensor:
        """z: [batch, nz, 1, 1]"""
        return self.main(z)


class DCGANDiscriminator(nn.Module):
    """DCGAN の Discriminator（64×64 画像識別）"""
    def __init__(self, nc: int = 3, ndf: int = 64):
        super().__init__()
        self.main = nn.Sequential(
            # 入力: [B, nc, 64, 64]
            nn.Conv2d(nc, ndf, 4, 2, 1, bias=False),
            nn.LeakyReLU(0.2, inplace=True),
            # → [B, ndf, 32, 32]
            nn.Conv2d(ndf, ndf * 2, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ndf * 2),
            nn.LeakyReLU(0.2, inplace=True),
            # → [B, ndf*2, 16, 16]
            nn.Conv2d(ndf * 2, ndf * 4, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ndf * 4),
            nn.LeakyReLU(0.2, inplace=True),
            # → [B, ndf*4, 8, 8]
            nn.Conv2d(ndf * 4, ndf * 8, 4, 2, 1, bias=False),
            nn.BatchNorm2d(ndf * 8),
            nn.LeakyReLU(0.2, inplace=True),
            # → [B, ndf*8, 4, 4]
            nn.Conv2d(ndf * 8, 1, 4, 1, 0, bias=False),
            nn.Sigmoid(),
            # → [B, 1, 1, 1]
        )
        self.apply(weights_init)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.main(x).view(-1)
```

### GAN の学習ループ

```python
def train_dcgan(generator, discriminator, dataloader, num_epochs=200,
                nz=100, lr=0.0002, beta1=0.5):
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    generator = generator.to(device)
    discriminator = discriminator.to(device)

    criterion = nn.BCELoss()
    optim_G = torch.optim.Adam(generator.parameters(), lr=lr, betas=(beta1, 0.999))
    optim_D = torch.optim.Adam(discriminator.parameters(), lr=lr, betas=(beta1, 0.999))

    real_label = 0.9   # Label Smoothing（1.0 の代わりに 0.9）
    fake_label = 0.0

    for epoch in range(num_epochs):
        for i, (real_images, _) in enumerate(dataloader):
            batch_size = real_images.size(0)
            real_images = real_images.to(device)

            # ─────────────────────────────
            # Step 1: Discriminator の学習
            # ─────────────────────────────
            discriminator.zero_grad()

            # 本物画像での損失
            labels = torch.full((batch_size,), real_label, device=device)
            output = discriminator(real_images)
            loss_D_real = criterion(output, labels)
            loss_D_real.backward()

            # 偽画像での損失
            z = torch.randn(batch_size, nz, 1, 1, device=device)
            fake_images = generator(z)
            labels.fill_(fake_label)
            output = discriminator(fake_images.detach())  # G への勾配を止める
            loss_D_fake = criterion(output, labels)
            loss_D_fake.backward()

            loss_D = loss_D_real + loss_D_fake
            optim_D.step()

            # ─────────────────────────────
            # Step 2: Generator の学習
            # ─────────────────────────────
            generator.zero_grad()
            labels.fill_(real_label)  # G は D を騙したい（本物ラベル）
            output = discriminator(fake_images)
            loss_G = criterion(output, labels)
            loss_G.backward()
            optim_G.step()

        if (epoch + 1) % 20 == 0:
            print(f"Epoch {epoch+1}: D_loss={loss_D:.4f}, G_loss={loss_G:.4f}")

    return generator, discriminator


# 画像生成
def generate_images(generator, num_images=64, nz=100):
    generator.eval()
    device = next(generator.parameters()).device
    with torch.no_grad():
        z = torch.randn(num_images, nz, 1, 1, device=device)
        fake_images = generator(z)
    return fake_images  # [-1, 1] の範囲
```

### WGAN-GP の Gradient Penalty

```python
def gradient_penalty(discriminator, real: torch.Tensor,
                     fake: torch.Tensor, device: str) -> torch.Tensor:
    """Wasserstein GAN の Gradient Penalty"""
    batch_size = real.size(0)
    alpha = torch.rand(batch_size, 1, 1, 1, device=device)
    interpolated = (alpha * real + (1 - alpha) * fake).requires_grad_(True)

    pred = discriminator(interpolated)
    grad = torch.autograd.grad(
        outputs=pred,
        inputs=interpolated,
        grad_outputs=torch.ones_like(pred),
        create_graph=True,
        retain_graph=True,
    )[0]

    grad = grad.view(batch_size, -1)
    grad_norm = grad.norm(2, dim=1)
    penalty = ((grad_norm - 1) ** 2).mean()
    return penalty

# WGAN-GP の D 損失
# loss_D = -mean(D(real)) + mean(D(fake)) + lambda_gp * gradient_penalty(...)
```

## GAN の主要バリアント

| モデル | 特徴 |
|---|---|
| CGAN | クラス条件付き生成 |
| Pix2Pix | 画像→画像の変換（ペアあり） |
| CycleGAN | ドメイン変換（ペアなし） |
| StyleGAN | スタイルベースの高品質顔生成 |
| BigGAN | 大規模クラス条件付き高品質生成 |
| WGAN-GP | 勾配ペナルティで安定学習 |

---

## 使用場面

- **画像生成**: 顔・風景・アート画像の生成
- **データ拡張**: 医療画像・希少クラスのデータ生成
- **ドメイン変換**: CycleGAN による馬→シマウマ変換
- **超解像**: 低解像度→高解像度変換（ESRGAN）
- **異常検知**: 正常データの分布を学習し異常を検知
