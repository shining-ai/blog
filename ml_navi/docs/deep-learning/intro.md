# 深層学習・応用

ニューラルネットワークの基礎から CNN・Transformer・NLP・強化学習・MLOps まで、深層学習と実践を体系的に解説します。

## カテゴリ一覧

- **ニューラルネットワーク基礎** — MLP・活性化関数・バックプロパゲーション・最適化
- **深層学習アーキテクチャ** — CNN・RNN・Transformer・生成モデル
- **自然言語処理** — Word2Vec・BERT・GPT・RAG
- **強化学習** — MDP・Q学習・DQN・方策勾配法
- **実践・ツール・MLOps** — PyTorch・Scikit-learn・実験管理・デプロイ
