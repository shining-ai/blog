# アルゴリズム

アルゴリズムとは、問題を解くための手順・手法の体系です。
データ構造と組み合わせて使うことで、効率的なプログラムを実現できます。

## ソートアルゴリズムの比較

| アルゴリズム | 最良 | 平均 | 最悪 | 空間 | 安定 | 特徴 |
| --- | --- | --- | --- | --- | --- | --- |
| バブルソート | O(n) | O(n²) | O(n²) | O(1) | ✓ | シンプル・遅い |
| 選択ソート | O(n²) | O(n²) | O(n²) | O(1) | ✗ | 交換回数が最小 |
| 挿入ソート | O(n) | O(n²) | O(n²) | O(1) | ✓ | 小規模・ほぼソート済みに強い |
| マージソート | O(n log n) | O(n log n) | O(n log n) | O(n) | ✓ | 安定・確実に速い |
| クイックソート | O(n log n) | O(n log n) | O(n²) | O(log n) | ✗ | 実用最速・ピボット選択が重要 |
| ヒープソート | O(n log n) | O(n log n) | O(n log n) | O(1) | ✗ | 追加領域不要・確実に速い |
| 計数ソート | O(n + k) | O(n + k) | O(n + k) | O(k) | ✓ | 非比較ソート・値域が小さい整数に有効 |
| 基数ソート | O(d(n+k)) | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✓ | 非比較ソート・桁数が少ない整数に有効 |

> **比較ソートの下限**: 比較をベースにしたソートは O(n log n) が理論的な下限です。
> 計数ソート・基数ソートはこの制約を超えられますが、値域に制限があります。

## 探索アルゴリズムの比較

| アルゴリズム | 計算量 | 前提条件 | 特徴 |
| --- | --- | --- | --- |
| 線形探索 | O(n) | なし | 最もシンプル・未ソートでも動作 |
| 二分探索 | O(log n) | ソート済み配列 | 高速・単調条件にも応用可能 |
| 三分探索 | O(log n) | 単峰関数（unimodal） | 関数の極値探索に特化 |

## グラフアルゴリズムの比較

### グラフ探索・最短経路

| アルゴリズム | 計算量 | 負の辺 | 特徴 |
| --- | --- | --- | --- |
| DFS | O(V + E) | - | 再帰/スタック・全探索・サイクル検出 |
| BFS | O(V + E) | - | キュー・重みなし最短経路 |
| ダイクストラ法 | O((V+E) log V) | ✗ | 非負辺の単一始点最短経路 |
| Bellman-Ford法 | O(VE) | ✓ | 負辺対応・負閉路検出 |
| Warshall-Floyd法 | O(V³) | ✓ | 全頂点対最短経路 |

### 最小全域木・その他

| アルゴリズム | 計算量 | 特徴 |
| --- | --- | --- |
| Kruskal法 | O(E log E) | 辺ベース・Union-Find・疎グラフ向き |
| Prim法 | O((V+E) log V) | 頂点ベース・優先度付きキュー・密グラフ向き |
| トポロジカルソート | O(V + E) | DAGの依存順序・Kahn法またはDFS後順 |
| SCC（Kosaraju） | O(V + E) | 有向グラフの強連結成分分解 |
| LCA（ダブリング） | O(n log n) / O(log n) | 根付き木の最小共通祖先 |

### ネットワークフロー・マッチング

| アルゴリズム | 計算量 | 特徴 |
| --- | --- | --- |
| Ford-Fulkerson法 | O(E × max_flow) | 増加路ベース・概念の理解に有用 |
| Dinic法 | O(V² E) / O(E√V) | レベルグラフ・二部グラフで O(E√V) |
| 二部マッチング | O(VE) | ハンガリアンアルゴリズム・König定理 |
