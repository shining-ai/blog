# 分散システム・信頼性

CAP定理・Raft・Kafka・マイクロサービス・SREまで、分散システムと信頼性エンジニアリングを体系的に解説します。

## カテゴリ一覧

- **分散システム理論** — CAP定理・PACELC・一貫性モデル・Raft・Paxos
- **メッセージング** — Kafka・RabbitMQ・イベント駆動アーキテクチャ・ストリーミング処理
- **マイクロサービス** — サービスメッシュ・サーキットブレーカー・API Gateway・サービスディスカバリ
- **信頼性・SRE** — SLO・SLA・エラーバジェット・カオスエンジニアリング・オブザーバビリティ
